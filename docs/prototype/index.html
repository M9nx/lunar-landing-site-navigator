    What this prototype demonstrates

    It demonstrates the comparison interaction and labels intended for a future data-backed tool. A validated version will need date-specific Sun and Earth geometry, documented coordinates and reference frames, and a stated horizon model. Terrain-clear visibility and radio-link availability must be distinguished.
