Data contract, frames, and limitations
  • Mode: SIMULATION / PRACTICE — challenge dataset not assumed.
  • Centre-ray only: compares disc centre direction to synthetic terrain horizon; not power, comms, or safety.
  • States: clear, blocked, unknown — unknown never maps to clear (see engine tests).
  • Replay source: deterministic hourly synthetic angles + toy terrain (Malapert gap / ridge); replace via adapter in backend/simulation/.
  • Transport: SSE for one-way updates; control plane uses POST on the same API.
  • Science gate: POST /v1/compare remains gated; this route is separate under /v1/simulation/.
